Color Guide

HEX: A compact color code used online, like #7C3AED.
RGB: A color format made from red, green, and blue values.
HSL: A color format based on hue, saturation, and lightness.
Hue: The basic color family, like red, orange, green, blue, or purple.
Saturation: How intense or muted a color is.
Lightness: How light or dark a color is.
Gradient: A smooth blend between colors.
Linear Gradient: A gradient that moves in a straight direction.
Palette: A group of colors meant to be used together.
Contrast: How different two colors are from each other.
